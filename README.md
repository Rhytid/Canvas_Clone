# What is this

A website that allows a user to log in as a student or teacher, 
Teachers are able to create edit and delete assignments each with a vriety of questions including essays and coding questions
Students are able to look at the assignments a teacher posts and take them. After submission students will be given a grade and feedback based on what the teacher set.
Assignments can be exported and imported 
Assignments can also be converted into a word document for easy printing
